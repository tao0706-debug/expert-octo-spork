# 题跋单独修订的参考记录

本次仅替换画内右侧小字题跋，调整其竖列、尺寸、淡墨与落款小印。主标题、正文界面字体、画材、构图、交互、手机布局不变。

## 检索与证据范围

- 尝试检索故宫博物院《张择端清明上河图卷》藏品页：https://www.dpm.org.cn/collection/paint/228226.html 。当前运行环境的网络代理返回 403，未能直接读取馆藏页或高清题跋原图。
- 搜索公开项目中的原卷资料：https://github.com/Rising1234Sun/qingmingshanghetu/blob/main/docs/素材来源.md 。该项目注明原卷图片取自 Wikimedia Commons 的 `Alongtheriver_QingMing.jpg`，标为 PD-Art；其分段预览可观察画卷与鉴藏印，但不包含可清晰临摹的完整卷后跋文。因此没有把该预览描述为高清题跋参考。
- 检索到包含《跋张择端清明上河图》文字的公开语料讨论：https://github.com/bmschmidt/wordVectors/issues/64 。该文本涉及金张著、元杨准等题跋记录，仅作二手文字线索，不作为书迹、版本或字体认定依据。

## 本作采用方式

这是一份原创题跋的瘦金体意趣重绘：细瘦挺拔的楷书、疏朗竖列、低起小款、略褪的炭墨，以及款下小朱印。并不声称《清明上河图》的题跋都使用瘦金体，也不直接挪用历史名家署名或鉴藏章。

题文沿用本作原创的“山非故山水非故水”“借万物之形写无有之境”“云生不知处舟渡未有乡”，落款为“丙午秋日偶记”“无何有主人”。图像中的生成式书写仍可能有笔画差异，不是某一历史字体字库的精确复制。

素材：`assets/scroll/colophon-shoujin.webp`。运行 `scripts/prepare_colophon.py` 只更新嵌入资料的 `inscription` 字段；`paper`、`title`、`seals` 字段逐字节保持不变。全量装裱打包脚本也会保留这份题跋覆盖素材。
