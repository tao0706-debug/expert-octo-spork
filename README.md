# 無何有之鄉 · 虚构山河卷

一张可交互的旧画卷。枯黄宣纸、纤维与旧痕、绫边和卷轴贯穿整页；以笔墨题跋和磨损朱印融入山水，不再展示画材库或素材数量。

## 打开

直接打开 **`无何有之乡.html`**，约 8 MiB，样式、逻辑、图像均已内嵌。支持现代桌面和手机浏览器，不需要联网、密钥或后端。手机聊天软件的文档预览器可能不执行 JavaScript，需使用浏览器打开。

开发版保留 `index.html`、`style.css`、`app.js`、`assets/ink-library.js` 和 `assets/scroll-materials.js` 的相对位置。可用以下命令启动静态服务：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## 观画

- 点击画卷、“另造一境”或空格键：二十四境同时解体、墨粒回旋并重新落墨。
- 平远 / 奇境 / 幻境与“幻度”：调整下一卷的倒置、倾斜、剪切、缩放和曲面变形。
- “细观”：全卷与原大切换，原大后可左右滑动。
- “藏卷”：导出带同一宣纸、题跋和印章的 3320 × 1450 PNG。
- “观二十四境”：临时显示分区辅助线，不写入导出的图片。
- “听风”：主动开启的本地合成风声。
- “卷末记”：简短创作说明。画材由 AI 预先生成，在本机重组；没有伪装在线 AI 调用或等待网络请求。

## 整体构图与融合

二十四境是独立重组单元，不再按可见的 6 × 4 网格铺画。每卷先选取“溪山平远／一水两岸／云岭回环”的全局骨架，再将 8 个远景、10 个主景、6 个近岸单元依山势安排；随机片段服从统一的空间层次。

画材先去除原有纸底，转换为统一墨色；根据笔墨密度推导不规则遮挡蒙版，避免矩形接缝和重复叠墨。覆盖整幅的连续水脉、云气与边缘留白统一处理，透出同一张宣纸。远景淡、主景浓，局部扭曲不会覆盖全局的云水秩序。

题签和题跋使用预生成的飞白笔墨图像；六枚篆印保留印泥颗粒、断线和不均匀转印。纸纹来自独立的旧宣纸材质图，页面、画芯、细观和导出均使用同源材质。页面是一件仿古数字创作，不是古物鉴定样本，题跋中的生成字形可能有误差。

## 资源与维护

- `assets/ink-library.js`：48 幅内嵌 WebP 画材，36 幅新 AI 局部与 12 幅原案例片段。
- `assets/manifest.json`：画材分组、名称、裁切坐标。
- `assets/sources/`：原始画材图版。
- `assets/scroll-materials.js`：旧宣纸、书法题签、题跋、篆印的嵌入数据。
- `assets/scroll/`：保留上述装裱资源的高质量来源图。
- `scripts/prepare_assets.py`、`scripts/prepare_scroll.py`：提取并打包生成资源，维护时需 Python 与 Pillow；运行网页不需要这些依赖。
- `scripts/build_standalone.py`：用 Python 标准库重建单文件离线版；修改页面、样式、逻辑或资源后需重新执行。
- `scripts/smoke.cjs`：Playwright / Chromium 集成测试；静态服务启动后执行 `node scripts/smoke.cjs`，可用 `ATLAS_URL`、`CHROMIUM_PATH` 指定地址和浏览器。

集成测试覆盖画材加载、24 个唯一主景、全局构图、连续生成差异、三种模式、像素动画、PNG 尺寸、细观、分区、印章渲染、隐藏画库入口、手机尺寸、声音和断网单文件重载。

使用当前隔离环境的现有仓库，无需创建 Git worktree。网页使用 Canvas 2D 与原生 JavaScript；没有在线字体请求、CDN、分析跟踪、在线模型或 Houdini 依赖。作品借《天书》中似是而非的观念进行独立创作，非徐冰作品，亦不对应真实地理。

## 正常 HTTP / HTTPS 打开与发布

聊天中的工作区文件链接不是公网网站，有些客户端会显示源码或阻止脚本。开发验证使用 `python3 scripts/serve.py --port 8080`，该服务明确发送 `Content-Type: text/html; charset=utf-8`，并正确区分 JavaScript、CSS 与图像 MIME 类型。

`.github/workflows/pages.yml` 在推送 `main` 后打包并部署 GitHub Pages，发布包仅含入口、样式、逻辑及两份画材数据。GitHub 仓库 Settings → Pages 的 Source 必须设为 **GitHub Actions**。预期网站地址为 `https://tao0706-debug.github.io/expert-octo-spork/`；只有 Pages 已启用、部署成功并完成公网访问验证后，才可视为已上线。

此云环境目前需要允许 `api.github.com` 以设置和查询 Pages，并允许 `tao0706-debug.github.io` 以验证公网结果。网络配置草稿已保存；保存草稿不会自动更新运行实例。

## 云水虚实与手机游观

中景水脉的宽度、透墨率和三处连通节点随卷变化，远岸以淡墨显隐，避免形成贯穿整幅的纯空白带。另有十二幅新生成的 AI 水墨素材：六种奇幻生物与六种雾桥、浮岛、倒瀑等连接景象。每卷选择三种生物与六处浓淡不等的过渡场景，局部雾窗让生物可辨，同时保持大局留白。它们与原有建筑共用墨色、纸纹和羽化方式。

桌面完整展示横卷；700px 以下屏幕默认以约 54svh、至少 330px 高度游观同一张横卷，可原生左右滑动。下方缩略图指示视野并可定位；“全卷”切换到完整构图，“游观”返回大幅画面。滑动手势不会触发重新生成，旋转屏幕后自动适配，收藏始终导出完整原卷。

新增资源为 `assets/wonders-library.js` 与 `assets/sources/wonders.webp`；执行 `python3 scripts/prepare_wonders.py` 可重新提取打包。发布包和单文件生成脚本均已包含这份资源。公网资源使用版本参数刷新 CSS 与逻辑缓存。

## 工写兼备与正楷指引

当前全部画材已重新绘制，包括三组建筑地景、整幅山水底景、六种生物和六种云水连接。建筑保留界画与细笔，树石云水采用块面、干笔、破墨和浓淡渗化，避免以西方均匀排线塑造全部景物。墨色映射保留中间调，解体动画的墨粒改为随流场弯曲的细墨丝。

题签、题跋使用新生成的颜体楷书风格图像，端正结体，不再使用行草。界面与部分画内文字嵌入 `Atlas ZhengKai` 正楷字体，基于 DyslexicKai Mono 的汇文正楷字身裁字并按上游保留名称要求重命名；该界面字库不是颜真卿碑帖的原样复刻。字体为约 78 KiB 的 WOFF2，位于 `assets/fonts/atlas-zhengkai.woff2`，通过 `assets/font-library.js` 内嵌，离线仍可使用。授权、署名和来源详见 `assets/fonts/LICENSE.txt` 与 `NOTICE.txt`；保留了字体内部的上游版权元数据。不可单独出售字体文件。

维护时从 https://github.com/DraftingDreamer/FontDyslexicKai 获取字体及许可，执行 `python3 scripts/prepare_font.py <源字体.ttf>` 后再构建单文件版。字体维护需要 fontTools 与 Brotli，网页本身不需要安装。新增界面文字后请重新裁字以覆盖新字。

主要按键有边框、较大的文字和说明，手机触控目标至少 44px，主操作独占一行。画面上方提供“观画小引”和“如何游观”展开说明；缩略图、全卷、细观、收藏与下卷意境均保留。
